DIT Parking Manager - Simple Project Explanation

Project: Parking management system for Dar es Salaam Institute of Technology (DIT).

Main idea: Hii application inasaidia kusimamia parking: magari, parking slots, check-in, check-out, payment, tickets, na reports.

Stack: Frontend: React + TypeScript + Vite. Backend: Spring Boot + Java. Database: PostgreSQL.

1. Project Logic Kwa Urahisi

  1. User ana-login kama Admin au Customer.
  2. Customer ana-register gari lake, mfano car, truck, au motorcycle.
  3. System inaonyesha parking slots zilizopo: Standard, VIP, na Disabled.
  4. Vehicle ikiingia parking, system inafanya check-in, inachagua slot, na kutoa ticket.
  5. Vehicle ikitoka, system inafanya check-out na kuhesabu fee.
  6. Customer/admin analipa kwa Cash, Card, au Mobile Money.
  7. Admin anaweza kuona reports za revenue na occupancy.

A. Abstraction and Inheritance: User, Admin, Customer

public abstract class User {
    public abstract String roleName();
    public abstract boolean canOperate(Vehicle vehicle);
}

public class Admin extends User {
    @Override
    public String roleName() {
        return "ADMIN";
    }

    @Override
    public boolean canOperate(Vehicle vehicle) {
        return vehicle != null;
    }
}

public class Customer extends User {
    @Override
    public String roleName() {
        return "CUSTOMER";
    }

    @Override
    public boolean canOperate(Vehicle vehicle) {
        return vehicle != null && this.equals(vehicle.getOwner());
    }
}

Meaning: Admin can operate any vehicle. Customer can operate only own vehicle.

11. Main Flow Ya Application

  1. Login: User enters username and password.
  2. Vehicle: User registers or manages vehicle.
  3. Slot: System checks available parking slot.
  4. Check-in: Vehicle is assigned to a slot and ticket is issued.

12. Fee Calculation Logic

public BigDecimal calculateFee() {
    return vehicle.hourlyRate()
            .multiply(slot.rateMultiplier())
            .multiply(BigDecimal.valueOf(billableHours()))
            .setScale(2, RoundingMode.HALF_UP);
}

Meaning rahisi: Parking fee = vehicle hourly rate x slot multiplier x hours.

  • Car: TSh 2,000 per hour.
  • Truck: TSh 5,000 per hour.
  • Motorcycle: TSh 1,000 per hour.
  • VIP slot multiplier: 1.5.
  • Partial hours are rounded up.

14. Backend Spring Boot Example

@Service
@Transactional
public class VehicleService {
    public void delete(User actor, Long id) {
        Vehicle vehicle = requireById(id);
        requireCanManage(actor, vehicle);

        if (sessionRepository.existsByVehicle(vehicle)) {
            throw AppException.conflict("Cannot delete vehicle with parking history.");
        }

        vehicleRepository.delete(vehicle);
    }
}

Meaning: Backend checks permission and safety before deleting a vehicle.
